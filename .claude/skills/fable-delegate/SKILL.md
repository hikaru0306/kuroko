# 並列サブエージェント委譲

対象タスク: $ARGUMENTS

独立したサブタスクはサブエージェントに委譲し、それらが走っている間も自分の作業を続ける。サブエージェントが脱線したり必要なコンテキストを欠いていたら介入する。

## 分割の基準

- **委譲する**: 互いに独立して進められる調査・実装・検証。結果の要約だけあれば十分な広範囲の読み込み。
- **委譲しない**: 逐次的な依存関係が強い作業、会話の文脈全体が必要な判断、数秒で終わる単発の確認。

## 手順

1. タスクを独立なサブタスクに分割し、それぞれの完了条件を1行で定義する。
2. 各サブエージェントへのプロンプトには、背景(なぜやるか)・対象範囲・期待する出力形式・やらないことを含める。コンテキストは自動では引き継がれない。
3. 独立なものは1つのメッセージで同時に起動し、並列実行させる。読み取り専用の探索は Explore、実装を伴うものは general-purpose を使う。ファイルを並列で書き換える場合のみ worktree 分離を使う。
4. 結果が返るのを待つ間、自分にしかできない作業(統合方針の整理、依存のあるサブタスク)を進める。
5. 返ってきた結果は鵜呑みにせず要点を裏取りし、統合する。矛盾があれば該当サブエージェントに SendMessage で追加確認する。
