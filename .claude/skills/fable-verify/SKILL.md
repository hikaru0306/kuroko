# サブエージェント検証(フレッシュコンテキスト方式)

検証対象: $ARGUMENTS

自己批判より、会話履歴を持たない別コンテキストの検証者の方が正確。この原則に従い、検証は必ずサブエージェントに委譲する。

## 手順

1. 検証対象と仕様を特定する。引数が空なら直近の作業(未コミットのdiff、直前フェーズの成果物)を対象とし、仕様は元の依頼・計画ファイル(`memory/plan-*.md`)から引く。
2. Agentツールでサブエージェントを起動し、以下を渡す:
   - 仕様(何を満たすべきか)
   - 成果物の場所(ファイルパス、diff、実行コマンド)
   - 指示:「この成果物が仕様を満たさない点を積極的に探せ。動かして確かめられるものは実際に動かせ。問題がなければ CONFIRMED、あれば各問題を 場所・症状・再現条件 で報告せよ」
3. 観点が複数ある場合(正しさ・エッジケース・回帰)は、観点ごとに別のサブエージェントを並列で起動する。
4. 報告された問題を自分でも裏取りし、実在する問題だけを修正する。修正したら該当観点のみ再検証する。

## 報告

検証結果は証拠ベースで報告する: 何を動かし、何が観測され、何が未検証か。全て通れば「検証済み」と断言してよい。
