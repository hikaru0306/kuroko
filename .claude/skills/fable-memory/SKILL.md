# 外部メモリシステム

$ARGUMENTS

会話の全履歴を持ち回るのではなく、計画・決定・発見を外部ストアに永続化し、そこから読み出す。保存先はこのリポジトリの `memory/` ディレクトリ:

```
memory/
  plan-*.md        # タスクごとのフェーズ計画(/fable-plan が作成)
  lessons/*.md     # 教訓ノート(1教訓1ファイル)
```

## 教訓の書き方(record)

1教訓1ファイル、冒頭に1行サマリ。修正された間違いと、確認できた有効なアプローチの両方を、なぜ重要だったかとともに記録する。

- リポジトリやチャット履歴に既に記録されていることは保存しない。
- 既存ノートと重複する内容は新規作成せず既存ノートを更新する。
- 間違いだと判明したノートは削除する。
- ファイル名は内容が分かるケバブケースにする(例: `lessons/build-requires-node20.md`)。

## 参照(recall)

トピックに関連するノートを `memory/lessons/` から検索して要約し、現在の作業にどう効くかを述べる。作業開始時に関連ノートがあれば自発的に参照してよい。

## 過去履歴からの初期構築(bootstrap)

過去のセッション・コミット履歴・PRを振り返り、サブエージェントを使って中心的なテーマと教訓を抽出して `memory/lessons/` に保存する。以後の作業で `memory/` を参照することを忘れないこと。
